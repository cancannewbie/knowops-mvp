# MVP 范围与后续

## 已实现

- React 中文七个业务入口，桌面和窄屏布局，加载、空、失败、取消状态。
- 服务端会话、角色与资料范围授权；不存在基于 userId 请求头的信任。
- Markdown/TXT/简单文本 PDF，真实异步处理、预览、失败重试与尝试隔离。
- PGlite 文件数据库和 pgvector；资料、运行事件及评测结果持续保存。
- 修订与知识发布清单；不把处理成功自动当成发布成功。
- 版本与权限过滤检索、本地字面特征向量、真实 Embedding HTTP 配置。
- 摘录演示、OpenAI-compatible 流式适配、事件回放、取消和生成终态。
- 段落/页码引用、来源预览、运营 trace、反馈、版本化测试集及 A/B 执行。
- 规则检查和独立人工复核；反馈转新测试集。
- 自动化测试、真实 Chromium 浏览器链路与截图、CI 配置。

## 对原生产设计的明确缩减

| 原设计 | 本 MVP | 原因与后续 |
|---|---|---|
| 独立 PostgreSQL | PGlite 本地 PostgreSQL | 无 Docker 即可启动；部署时迁移连接池与备份 |
| Redis / BullMQ / 独立 worker | 数据库任务 + 单进程调度 | 真实持久状态和重启恢复；未实现分布式锁和跨实例消费 |
| 中文语义 Embedding | 默认 48 维字面特征哈希 | 方便无凭据验收；真实向量需配置服务并重建修订 |
| 商业模型实际问答 | 默认确定性原文摘录 | 不产生未知费用；适配协议已由受控 HTTP 上游验证 |
| 复杂 PDF、OCR | 文本层 PDF 提取和原文件页码打开 | 无 OCR、复杂表格还原和精确高亮 |
| 可调整多版本模型配置 | A/B 两个固定检索配置 + trace 记录 | 暂无任意提示词/模型配置发布管理页 |
| 企业级质量指标 | 关键词/拒答规则 + 人工复核 | 不冒称语义准确率、Ragas 或专家评分 |
| 按文档精细停止相关生成 | 权限变更保守停止当前空间全部生成 | 防止检索阶段尚无 refs 时遗漏；可能影响无关生成 |
| 多工作空间运营 | 一个演示空间，数据查询带空间边界 | 暂无空间创建和成员管理界面 |
| 大型全文检索与近似向量索引 | 完整授权小集合精确排序 | 不宣称大规模吞吐或经过企业负载验证 |

## 仍待外部验证

- **商业生成模型 / Embedding**：没有提供或使用真实凭据；模型效果、token 用量、费用和限流策略未做端到端验证。
- **公开部署**：源码仓库公开不等于应用已上线。
- **生产安全与可用性**：默认已知演示账户必须替换；需 HTTPS、安全 Cookie、备份恢复、持久对象存储、资源额度、访问审计和日志治理。
- **多实例**：PGlite 数据目录只允许当前单进程持有。不要让多个实例共享同一个目录。

## 已知限制

- 资料大小 5 MB，单份最多 2000 个片段；没有超大 PDF 的独立进程隔离。
- 默认 100 条最近问答列表，没有无限历史检索。
- SSE 事件在本地完整保留，尚无事件压缩/过期清理。
- 队列在同一进程串行处理入库和批量评测；大型批次会延迟其他后台任务。
- 引用 ID 校验不证明答案语义正确；相似度不等于模型信心。
- 上游取消是尽力停止请求，不承诺供应商停止计费。
- 权限收回阻止后续访问，不能远程删除用户已接收的副本。
- 自动化 A/B 使用虚构八题，不代表真实业务效果与生产数据分布。
