# 七分钟演示路线

运行 `npm ci`、`npm run build`、`npm start`，打开 http://127.0.0.1:5413。

## 1. 登录和整体业务

使用 `admin@example.test / DemoPass123!`。概览中的资料数来自数据库。顶部明确显示当前 provider，默认“确定性摘录演示”。

## 2. 上传与发布

进入“知识资料”，上传本地 Markdown/TXT。也可复制以下虚构资料保存为 `delivery.md`：

```markdown
# 交付检查清单

DELIVERY_CHECK 交付校验：先完成数据库备份，再执行上线检查。需要实施负责人和测试负责人共同确认。
```

选择 V2、团队共享。到“处理任务”查看阶段。就绪后回到资料预览片段。

选择“最新就绪资料”，输入发布名称，点击发布。发布清单包含被选择的全部资料；没有勾选的资料不会被新问答使用。

失败演示：上传只有空格的 TXT；任务会进入失败并显示原因。重试仍对同一原文件执行；要修正文档内容应上传新修订。

## 3. 问答与引用

进入“问答工作台”，选择 V2 和配置 B，提问：

- `V2 成员导入限制是多少？`
- `IMPORT_EMAIL_DUPLICATE 怎么处理？`
- `DELIVERY_CHECK 如何完成交付？`

点击 S1 来源按钮，查看资料修订、段落和原文。PDF 引用可打开原文件对应页。将产品改为 V3，提问自动合并账户，展示资料不足。

## 4. 诊断与反馈

在回答下点击“反馈问题”，写入原因。运营者到“检索诊断”选择运行，核对授权过滤、候选片段、最终上下文、检索时间和首段正文时间。

到“反馈案例”，点击加入测试集，填写预期关键词或“应拒答”，选择执行身份，保存测试集新版本。

## 5. A/B 评测

选择默认回归集 v1，运行 A/B。8 道题生成 16 条配置结果。等待该次记录显示已完成，查看每题的 A/B 差异。

综合问题需要条数、格式与管理员角色三个要点，单片段 A 可能遗漏要点，B 可以检索多片段。实际记录决定显示结果，不预填分数。

打开逐题结果，核对原文后标记“原文支持答案”或“存在无依据结论”。规则命中和人工复核是两种证据。

## 6. 权限、取消、恢复

另开无痕窗口登录 `member@example.test`。成员看不到运维资料，也不能查询“客户部署”中的受限配置。普通用户不能访问运营诊断或评测接口。

为便于观察取消，可上传较长的虚构手册；开始生成后点击停止。服务端终态固定为取消，迟到增量不会继续追加。

刷新页面后，从会话列表选回原问题。已完成记录恢复；生成中连接以游标回放。服务端重启会把未完成生成标为中断，并保留部分正文。

## 演示边界

默认回答来自确定性原文摘录。真实商业模型效果、费用与公开部署均未验证。受控 HTTP 测试只证明上游协议适配和故障处理，不能代替模型质量评价。
